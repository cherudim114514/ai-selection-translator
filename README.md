# AI 选词翻译

一个基于 Manifest V3 的浏览器插件。选中网页文字后，点击选区旁的“翻译”按钮，插件会调用用户配置的 OpenAI 兼容 API，并在浮层中流式显示译文。也可以对网页图片使用右键菜单识别二维码。

## 使用方法

1. 打开 Chrome 的扩展管理页面。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开插件的扩展详情，进入“扩展程序选项”。
5. 填写 API Base URL、API Key 和模型名称并保存。
   API Key 输入框旁的“查看 API Key”按钮可以临时显示或隐藏当前 Key。
6. 刷新已经打开的网页，选中文字后点击翻译按钮。
   在可编辑文本（输入框、文本域或 contenteditable）中，翻译完成后可以点击“替换原文”直接写回译文。
7. 在网页图片上点击鼠标右键，选择“识别二维码”，识别结果会显示在网页浮层中，可以直接复制。

在“翻译偏好”中可以分别设置两条翻译方向：非中文文本使用默认输出语言；开启“中文自动翻译为其他语言”后，检测到中文时使用单独配置的中文文本输出语言。中文检测在本地完成，不会产生额外 API 请求。

默认配置适用于 OpenAI Chat Completions API。其他服务商需要提供兼容的 Base URL 和模型名称。

## 安全和权限

- API Key 仅保存在当前浏览器的 chrome.storage.local 中。
- 选中文字会发送给用户在设置中填写的 API 服务商。
- 二维码解码使用插件内置的 jsQR，在本地完成，不会上传图片或二维码内容。
- 插件使用 all_urls 权限，是为了在普通网页中监听选中文字；浏览器内部页面（例如 chrome://）不允许扩展注入。
- 不要在不信任的设备上填写高权限或长期有效的 API Key。

## 当前限制

- 单次选中文字最多 6000 个字符。
- 第一版针对普通网页文本，复杂编辑器、跨域 iframe 和 PDF 阅读器可能不支持。
- 二维码功能针对右键点击的普通网页图片；需要登录权限、禁止扩展读取或使用 blob 地址的图片可能无法下载识别。
- “替换原文”只会出现在仍然有效且位于可编辑区域的选区中，普通网页正文不会被改写。
- API 需要兼容 OpenAI 的 /chat/completions 接口；优先使用流式 SSE，也兼容标准 JSON 返回。
